# Retail Sales Analysis Dashboard using SQL and Power BI

## Project Overview
This project focuses on analyzing retail sales data using SQL and Power BI to generate business insights and interactive visualizations. The dashboard helps understand sales performance, profit trends, customer behavior, and regional analysis.

---

## Tools & Technologies Used
- SQLite
- SQL
- Power BI Desktop
- VS Code
- Git & GitHub

---

## Dataset
The dataset contains retail sales transaction data including:
- Order ID
- Order Date
- Customer Name
- Region
- Category
- Product Name
- Quantity
- Sales
- Profit

---

## SQL Analysis Performed
The project includes:
- Aggregate functions
- GROUP BY analysis
- Filtering and sorting
- Joins
- Common Table Expressions (CTEs)
- Window Functions
- Ranking Functions
- Running Totals
- Profit Margin calculations

---

## Power BI Dashboard Features
- Dark themed interactive dashboard
- KPI Cards
- Sales Trend Analysis
- Sales by Region
- Category Distribution
- Top Customers Analysis
- Area Charts
- Donut Charts
- Interactive Slicers and Filters

---

## Key Business Insights
- Technology category generated the highest sales
- North region showed strong sales performance
- Monthly sales trends revealed growth over time
- Certain customers contributed significantly to total revenue
- Profit margins varied across categories

## How to Run the Project

### SQL
1. Open SQLite
2. Load `retail.db`
3. Run queries from `analysis.sql`

### Power BI
1. Open Power BI Desktop
2. Import `sales.csv`
3. Open dashboard file or recreate visuals
